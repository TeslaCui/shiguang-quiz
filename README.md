# 拾光题库

面向中华文化考研复习的静态 PWA。内置“中华文化知识库”（2023 港澳台大赛官方 2000 题 + 教材/押题 241 题 + Z002 阅读题 12 题，共 2253 题），支持智能选题刷题、冲刺重点优先、阅读题、即时判题与解析、错题本、按遗忘曲线的复习调度，以及 Supabase 账号体系（刷题记录、错题本、复习计划均按账号独立存储）。

## 数据说明

- 题库来源：2023 全国港澳台大学生中华文化知识大赛官方资料（Excel），共 2000 条——单选题、多选题、判断题、填空题各 500 道，题干、选项、正确答案与解析均取自官方数据，未伪造干扰项。
- 判断题以「正确 / 错误」两选项作答；填空题无官方选项，网页端采用「显示答案 + 自评」的填空模式刷题。
- 完整题库 Excel（题目 / 选项A-D / 答案 / 解析 / 质量状态）：`中华文化考研题库_2023全国港澳台大赛_官方版.xlsx`。
- 题库由 `build_official_bank.mjs` 从官方 Excel 重新生成（`questions.json` 供网页使用）。
- 教材与押题（按 Z002 高频预测命题，带出处页码）：《中国文化史概要（增订二版）》与《中国古代文化常识》各章代表性内容经视觉识别命题 241 条，来源标记 `…·教材命题`，均计入**冲刺重点池**。
- **冲刺重点池（priority=1，共 1266 条）**：官方题中命中 Z002 高频主题（文学作家作品/诸子/科举职官/节令/科技医药/艺术/纪年称谓等）的 1025 条 + 全部教材押题；刷题新题阶段“重点优先”出题，首页显示“冲刺重点 N 题”。
- **阅读题（对应 Z002 阅读 15 分题型）**：来源 `Z002阅读题·精选`，为“阅读材料 + 单选”形式（大纲样题《荀子·劝学》、汪曾祺《寻根》、儒家《论语》材料各 4 小题），与常识题同库练习。
- 高频考点预测清单见 `docs/Z002高频考点清单.md`（按必考/高频/有概率三档列知识点）。
- 历史遗留的损坏/OCR 低质题目（题干丢失或乱码）已从正式题库移除，旧数据备份在 `outputs/legacy_questions_2713.bak.json`。

## 使用

打开部署后的 HTTPS 地址即可使用。**数据模型**：

- 每个账号（含未登录的本机匿名空间）有独立的刷题记录、错题本与复习计划，互不串数据；登录后自动载入该账号在 Supabase 的云端数据，退出登录切回本机空间。
- 前端将每题维护一个复习箱（答对升级间隔、答错清零回炉），选题时**到期复习优先 → 薄弱/错题加权 → 新题随机（冲刺重点 priority=1 先出）（冲刺重点 priority=1 先出）**，错过的题会以更高频率再次出现；首页提供「今日复习任务」一键入口，到期与薄弱题答对即出队、答错自动回炉。
- 需要跨设备同步复习计划时，请在 Supabase SQL Editor 执行 `supabase_schema.sql`（新增 `review_state`、`practice_sessions` 表，含 RLS 与索引）；建表前功能自动降级为浏览器本地调度，不阻塞使用。
- **刷题记录按“会话”计**：进入练习到退出（或切走/关闭页面）记为一次，记录题数、正确率与用时；主页据此展示累计答题、正确率与打卡（连续/累计天数）。
- **账号登录**：注册需用户名 + 邮箱（手机号选填）；登录支持邮箱、手机号、用户名任一 + 密码（用户名经 RPC 映射到账号邮箱）。老账号若无邮箱仍可用手机号直接登录。

题库文件是公开静态数据，不包含用户账号私有信息。

题库页支持拖放或选择 `.xlsx/.xls/.json/.csv/.txt/.md` 文件进行浏览器端导入。PDF、Word、PPT 等格式会提示需要服务端解析，不会假装导入成功。

## 发布

将 `index.html`、`style.css`、`app.js`、`questions.json`、`manifest.json`、`sw.js` 一并部署到 GitHub Pages、Vercel 或 Netlify。更新后使用带版本参数的地址或强制刷新，避免旧 Service Worker 缓存。
